
# Knowledge Hub

知識カードを中心に、メモ・整理・記事化・公開管理まで行う同期アプリ。

## Concept

メモ

↓

知識カード

↓

整理・紐付け

↓

記事候補

↓

下書き

↓

公開済み

を一元管理する。

## Tech Stack

- React

- Vite

- TypeScript

- Supabase

- PostgreSQL

- PWA

- Future: Electron / Tauri

## Main Status

- inbox

- card

- article-ready

- draft

- published

- archived

- deleted
