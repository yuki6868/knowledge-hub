# Card CRUD Design

## commit 005 の範囲

この段階では Supabase にはまだ保存しない。
React のローカル state で、カード作成・編集・ゴミ箱移動・復元・完全削除の動きを確認する。

## 操作

### 新規作成

`+ クイックメモ` または編集パネルの `新規` から空フォームを開く。
保存すると `cards` state に追加する。

### 編集

一覧カードの `編集` を押すと、右側の編集パネルに内容を読み込む。
保存すると該当カードを更新する。

### 通常削除

通常削除は物理削除ではなく、次の状態変更にする。

```text
status = 'trash'
```

### 復元

ゴミ箱画面の `復元` で、次の状態へ戻す。

```text
status = 'card'
```

### 完全削除

ゴミ箱画面の `完全削除` からのみ実行する。
確認ダイアログを出したうえで、ローカル state から削除する。
