# Sync Status Design

## 目的

commit 010では、Supabase Realtimeを接続する前段階として、同期状態をUIで確認できる土台を作る。

## 表示する状態

- 同期済み
- 未同期あり
- 競合あり

## 表示する数値

- 未同期件数
- 競合件数
- 最終同期時刻
- 端末ID

## 現時点の扱い

この段階ではSupabaseへ実通信しない。
Reactのローカルstateで同期状態を仮管理する。

カードの作成、編集、ステータス変更、ゴミ箱移動、復元、完全削除を行うと、未同期件数が増える。

「同期済みにする」ボタンは、後でSupabase同期処理に置き換える。

「競合を仮作成」ボタンは、後で同一カードを複数端末で編集した場合の競合検出処理に置き換える。
