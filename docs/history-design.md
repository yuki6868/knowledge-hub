# 編集履歴設計

## 方針

カードを保存するとき、更新後ではなく更新前のタイトルと本文を `card_histories` として保存する。

```text
編集前カード
↓
履歴として保存
↓
カード本体を更新
```

## 保存対象

- title
- body
- saved_at

タグ、サイト、ステータスは現時点では履歴対象にしない。

## UI

カード編集パネルの下に編集履歴を表示する。

履歴の「フォームに戻す」を押すと、履歴のタイトルと本文を編集フォームへ戻す。
この時点ではまだ保存しない。
保存ボタンを押して初めて現在カードに反映される。

## 完全削除との関係

カードをゴミ箱から完全削除した場合、そのカードの履歴も削除する。

Supabaseでは `card_histories.card_id references cards(id) on delete cascade` により、DB上でも同じ挙動になる。
