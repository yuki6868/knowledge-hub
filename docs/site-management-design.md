# Site Management Design

## 目的

Knowledge Hubでは、カードを単なるメモとして並べるだけではなく、公開先・整理先ごとに見られるようにする。

対象サイト:

- Note
- AI時代の設計ガイド
- 世界遺産サイト
- その他

## commit 007 の範囲

このコミットでは、Reactのローカルstate上でサイト別ビューを追加する。

- サイト別カード数
- サイト別の記事候補数
- サイト別の下書き数
- サイト別の公開済み数
- サイトカードをクリックして一覧を絞り込み

## 削除カードの扱い

`status = trash` のカードは、サイト別集計から除外する。

ゴミ箱画面ではサイト絞り込みよりも、ゴミ箱表示を優先する。

## 今後

将来的には `sites` テーブルを作る可能性がある。

ただし現時点ではサイト種別が固定で少ないため、TypeScript定数で管理する。
